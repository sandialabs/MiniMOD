
# Remote Access Memory Channels (RAMC)

**This is the SANDIA (private) RAMC repo.**

The repo contains Sandia-specific run scripts, Sandia machine information (for NIC selection), 
and (perhaps) code that might fall under another license (for heat diffusion). 

The data and scripts used for 2026 CUG (in Nice, FR) paper is still in Whit's private 
'random' repo, as are earlier tests (e.g., game of life).
